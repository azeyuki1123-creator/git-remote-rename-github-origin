# 司法書士試験 学習記録アプリ

間違えたところを写真で溜めて、そこから自分の弱点の傾向を出し、「いつまでに何をやるか」に落とすための個人用アプリ。

## できること

| ページ | 内容 |
| --- | --- |
| ホーム | 本試験までの残り日数、復習期限、苦手ストック、直近7日の学習時間。学習時間の記録もここ。 |
| 記録する | 問題の写真をアップロードすると、AIが科目・分野・出典・押さえるべき論点・間違えた原因を読み取って保存。 |
| 苦手ノート | 蓄積した苦手を科目・復習期限・理解度で絞り込み。復習するたびに次回の復習日が自動で伸びる(間隔反復)。 |
| 成績 | 模試・答練・過去問演習の結果を科目別に記録し、正答率の推移を表示。 |
| 傾向分析 | 科目別の失点見込み、分野別の誤答、間違えた原因の内訳、学習時間の配分。 |
| 計画 | 分析から出てきた「やるべきこと」を月／週／日のタスクに落として管理。 |

### 弱点の出し方

中心にしている指標は **失点見込み = (1 − 正答率) × 本試験の出題数** です。

正答率が同じでも、出題20問の民法と出題1問の民事保全法では本試験への影響がまるで違います。この指標なら「どの科目を潰すと点が伸びるか」が問数で直接わかります。成績が未入力の科目は誤答ログの件数で代用し、成績も誤答ログも無い科目は「未計測」と表示します(得意という意味ではありません)。

計画ページの提案は、この失点見込みに加えて、誤答が集中している分野、復習期限を過ぎた問題、出題数の割に学習時間が足りていない科目から組み立てています。

## セットアップ

```bash
npm install
```

写真のAI解析を使う場合は Anthropic の API キーを設定します。

```bash
echo 'ANTHROPIC_API_KEY=sk-ant-...' > .env.local
```

キーが無くても、科目・分野を手入力すればすべての機能が使えます(AI解析のチェックボックスが無効になるだけです)。

```bash
npm run dev                  # http://localhost:3000
npm run build && npm start   # 本番
```

## データの保存先

すべて `data/` 以下に入ります。バックアップはこのディレクトリごとコピーすれば済みます。

- `data/study.db` — SQLite。記録・成績・タスクのすべて。
- `data/uploads/` — アップロードした写真。

`DATA_DIR` 環境変数で保存先を変えられます。デプロイ先で永続ボリュームをマウントする場合はそこを指定してください。

## 環境変数

| 変数 | 既定値 | 用途 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | (なし) | 写真のAI解析。未設定ならAI解析だけ無効になる。 |
| `CLAUDE_MODEL` | `claude-opus-5` | 解析に使うモデル。 |
| `DATA_DIR` | `./data` | DBと画像の保存先。 |

## 科目マスタ

`src/lib/subjects.ts` に11科目＋記述式2つと、それぞれの分野・本試験の出題数を定義しています。分野を足したいときはここを編集してください。AIの解析結果もこの一覧の中から選ばれます。

## 動作確認

開発サーバーを起動した状態で、主要な操作を一通り流すスモークテストを実行できます。

```bash
npm run dev
node smoke.mjs
```
